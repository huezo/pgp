# PGP Key Generator

Generador de claves **OpenPGP (PGP/GPG)** que funciona completamente desde el navegador. Permite crear pares de claves públicas y privadas de forma sencilla, sin necesidad de instalar software adicional.

## Características

- Generación de claves PGP.
- Compatible con RSA y ECC.
- Selección del tamaño de la clave.
- Configuración de expiración.
- Protección mediante contraseña (Passphrase).
- Descarga de las claves en formato `.asc`.
- Funcionamiento 100 % del lado del cliente.
